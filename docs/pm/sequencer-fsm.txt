States and transitions:
1. IDLE          --START-->                  LOAD_WEIGHTS
2. LOAD_WEIGHTS  --K x N loaded-->            LOAD_INPUT
3. LOAD_INPUT    --M x K loaded-->            COMPUTE
4. COMPUTE       --after M+K+N-2 cycles-->    READ_OUTPUT
                    (cycle counter starts at 0;
                     injects A[i][k] when i+k == cycle;
                     increments cycle each step)
5. READ_OUTPUT   -->                          WRITE_OUTPUT
6. WRITE_OUTPUT  --M x N values written-->    DONE
