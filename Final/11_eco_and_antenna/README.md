## 1. What this stage does

1) antenna loop (`fix_antenna.tcl` layer hopping, `antenna_port_buffers.tcl`), 2) hold ECO of 9 cells found by PrimeTime and applied in ICC2 (`pt_eco_probe.tcl`, `pt_eco_apply.tcl`), 3) data-limit ECO (9 resizes), 4) SI round (2 hold buffers, 1 resize, second `fix_antenna`). Each ECO: probe in PrimeTime -> change file -> apply in ICC2 behind gates -> new checkpoint.
